## 预览与导出（PPT/PDF）

### 方式A：本地直接预览 Markdown
- 使用 VS Code + Marp 插件打开 `微型热电器件封装岗位汇报_第7-14页.marp.md`。

### 方式B：命令行导出（需 Node.js）
```bash
npm i -g @marp-team/marp-cli
marp 微型热电器件封装岗位汇报_第7-14页.marp.md --html --allow-local-files
marp 微型热电器件封装岗位汇报_第7-14页.marp.md --pptx --allow-local-files
marp 微型热电器件封装岗位汇报_第7-14页.marp.md --pdf --allow-local-files
```

> 若环境缺少 Chromium，`--pdf` 可能失败；此时可先导出 `pptx` 或 `html`，再在本地办公软件/浏览器另存为 PDF。
